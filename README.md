# SpiroBird

SpiroBird je gamificirani IoT digitalni spirometar temeljen na ESP32 platformi. 
Potenciometar se koristi kao emulator protoka daha. Sustav očitava analogni signal, 
primjenjuje eksponencijalni klizni prosjek radi smanjenja šuma, računa protok i volumen, 
provjerava uvjete uspješne vježbe te prikazuje stanje na OLED zaslonu kroz jednostavno 
grafičko sučelje inspirirano Flappy Bird igrom. Dodatno, ESP32 omogućuje lokalni Wi-Fi 
dashboard za praćenje rezultata na mobilnom uređaju.
